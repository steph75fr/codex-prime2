# codex-prime2

Premier projet initialisé avec une page web statique prête pour GitHub Pages.

## Fichiers

- `index.html` — page d'accueil
- `style.css` — mise en forme responsive
- `script.js` — JavaScript minimal

## Publication avec GitHub Pages

Dans GitHub, ouvrez **Settings → Pages**, puis choisissez :

- **Source** : Deploy from a branch
- **Branch** : `main`
- **Folder** : `/ (root)`
